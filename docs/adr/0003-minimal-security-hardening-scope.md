# Security hardening scoped to essentials only, despite public deployment

Given the 1–3 month thesis timeline and bachelor-level project scope, security work for this round is limited to moving secrets out of the committed `docker-compose.yml` into a gitignored `.env` and adding server-side file-type/size validation on uploads. Login rate-limiting, an input-validation library (zod/joi), and other hardening are deliberately deferred to the thesis paper's future-work section rather than built now — even though the site will be reachable on a public cloud VM (see [0001](./0001-cloud-vm-deploy-containerized-ollama.md)). CORS is the one exception treated as a functional blocker rather than deferred hardening: it's hardcoded to `localhost:3000` today, and the site simply won't work from a public hostname until it reads from an env var.
